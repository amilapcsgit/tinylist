# NeonList 1.4 Release Notes

Release date: 2026-05-07

Highlights:
- Fixed Settings data action icons: Export now points outward/up, Import now points inward/down.
- Settings screen remains scrollable and compact on large/high-density phones such as Galaxy S25 Ultra.
- Import/export controls use full-width professional action rows for easier tapping.
- Settings now reports version `1.4 (18)` through the centralized Android build configuration.
