# NeonList 1.3 Release Notes

Release date: 2026-05-07

Highlights:
- First-run tutorial data now explains NeonList's offline-first workflow and gesture shortcuts inside the app.
- Added a luggage weight balancing demo list to showcase numeric totals and selected sums for real-world packing use.
- Clarified power gestures: hold + drag down adds near a row, and hold + drag up duplicates. A normal drag still scrolls.
- Improved long title handling on list and item rows so counters and action controls stay visible.
- Settings now reports version `1.3 (17)` through the centralized Android build configuration.
